# FRES-Net: Fast Residual Efficient Segmentation Network for Lightweight Crop–Weed Semantic Segmentation

Official repository for the paper:
> **FRES-Net: Fast Residual Efficient Segmentation Network for Lightweight Crop–Weed Semantic Segmentation**  
> *Indra Agustian, Igi Ardiyanto, Sunu Wibirama*  
> Department of Electrical and Information Engineering, Faculty of Engineering, Universitas Gadjah M0a, Yogyakarta, Indonesia.

---

## 📌 About The Project

**FRES-Net** is an ultra-lightweight, high-efficiency semantic segmentation network specifically designed for real-time, resource-constrained crop and weed discrimination in precision agriculture. 

This repository contains the complete implementation of FRES-Net, all ablation study variants, protocol-aligned baseline re-implementations, training/evaluation scripts, and computational profiling tools.

This repository will be made fully public upon formal acceptance of the manuscript.
